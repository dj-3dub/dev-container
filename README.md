# Dev Toolbox 2026

A comprehensive development environment with monitoring and CI/CD.

## Quick Start
- `make up-dev` : Start Dev tools (Rust, Python, AWS, etc.)
- `make up-mon` : Start Monitoring (Grafana at :3000, Prometheus at :9091)
- `make up-all` : Start everything

## Monitoring
- **Home Dashboard**: RHEL System Metrics (Node Exporter)
- **Container Dashboard**: Docker Metrics (cAdvisor)
